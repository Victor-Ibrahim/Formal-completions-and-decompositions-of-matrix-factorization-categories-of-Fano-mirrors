# Formal-completions-and-decompositions-of-matrix-factorization-categories-of-Fano-mirrors
This repository contains the code and calculations related to the article.
The `Appendix.tex` discusses the calculations for all open-torus Landau-Ginzburg potentials, while the file `Bd_V4d+2_compactified_gluing.tex` contains the calculations and comparisons regarding the compactifications of the $(B_d, V_{4d+2})$ potentials.
